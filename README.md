# 🏦 Loan Approval Prediction System

[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://loan-approval-balaji.streamlit.app/)

A machine learning web app that predicts whether a loan application will be approved based on applicant details.

## 🔗 Live App
👉 [Click here to open the app](https://loan-approval-balaji.streamlit.app/)

## 📊 Project Overview
- **Dataset**: 614 real loan applications
- **Target**: Predict Loan Approval (Yes/No)
- **Models Used**: Decision Tree, Random Forest, Gradient Boosting
- **Evaluation**: Accuracy and F1 Score

## ✨ Features Used
- Applicant Income
- Credit History
- Loan Amount
- Education
- Marital Status
- LoanIncomeRatio (engineered feature)

## 🛠️ Tech Stack
- Python
- Scikit-learn
- Pandas
- Streamlit

## 🎯 Business Impact
Helps banks make faster data-driven loan decisions and reduce default risk.
